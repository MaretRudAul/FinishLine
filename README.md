# FinishLine

## A Vandyhacks 2024 Submission

A single page application which scrapes Vanderbilt's Anchorlink website in order to find internship, networking events, and job opportunities based on important key words. Use filters to sort for opportunities that you personally are interested in.  

The Front-end was made using React, while the Back-end is a Flask project utilizing Selenium to scrape Anchorlink.
